# The Moon Finally Answers Back

A one-line entry for the make.fun bounty [The Moon Finally Answers Back](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1): a small Node program (`main.ts`) that writes a single line of text to `/output/entry.txt` — the Moon, after four billion years of wishes, howls, and 3 a.m. promises, finally answering back with one dry correction: it is a rock, not a vending machine, and there are no refunds.
